# Pinned web interaction references

This refinement uses original local implementations, informed by these public
version-matched patterns. No third-party source, stylesheet, image, font or new
runtime dependency is vendored by this change.

- [dash-bootstrap-components 1.4.1](https://github.com/dbc-team/dash-bootstrap-components/tree/1.4.1):
  `Input`/`Textarea`/`Select.invalid` and `FormFeedback` component contracts.
- [dash-bootstrap-templates V1.3.0 dbc.css](https://github.com/AnnMarieW/dash-bootstrap-templates/blob/V1.3.0/dbc.css):
  selective Dash dropdown/table theming patterns. The package and ThemeSwitchAIO
  are not installed; all colors use the workspace's local light/dark tokens.
- [Dash 2.9.1 graph responsive tests](https://github.com/plotly/dash/blob/v2.9.1/components/dash-core-components/tests/integration/graph/test_graph_responsive.py):
  distinguish actual rendered chart geometry from a present component shell.

The assistant remains unconnected. Interaction improvements do not enable a
model transport or change role, organization, report catalog or CRUD authority.
